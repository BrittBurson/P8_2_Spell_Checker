# CSC 242 Chapter 8 Group Project

## Project Description

This repository contains our group project for Chapter 8: Streams. The assignment includes two C++ programming projects, P8.2 Spell Checker and P8.7 Random Monoalphabet Cipher. The programs demonstrate the use of file streams, strings, vectors, functions, and file processing in C++.

## P8.2 – Spell Checker

**Completed by: Brittany Burson**

The P8.2 program is a spell checker that reads words from a dictionary file and stores them in a vector. It then reads words from another text file and compares them to the words in the dictionary. If a word cannot be found in the dictionary, the program displays the word as an unknown or misspelled word.

### P8.2 Files

* `P8_2_Spell_Checker.cpp` – C++ source code for the spell checker
* `dictionary.txt` – Dictionary used to check words
* `test.txt` – Sample file used to test the program
* Visual Studio project files

## P8.7 – Random Monoalphabet Cipher

**Completed by: JohnPaul Shaner**

The P8.7 program uses a keyword to create a random monoalphabetic cipher. The program can encrypt text from an input file and save the encrypted text to another file. It can also decrypt the encrypted text back into its original form.

The P8.7 project files are stored in the `P8_7_Random_Cipher` folder.

### P8.7 Files

* `P8_7_Cypher_source.cpp` – C++ source code for the cipher program
* `Keyword.txt` – Keyword information used by the program
* `input.txt` – Input used for testing
* `encrypted.txt` – Encrypted output
* `decrypted.txt` – Decrypted output
* `Shaner JohnPaul Pseudocode Assignment_5.docx` – Pseudocode documentation

## Testing

Both programs include test files to demonstrate their functionality. P8.2 checks words from a text file against a dictionary, while P8.7 demonstrates both encryption and decryption using file input and output.
